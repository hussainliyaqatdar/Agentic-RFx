# Seed dataset

Generated by `build_seed_data.py` (deterministic - `random.seed(42)`, safe to re-run):

```bash
cd data/seed
uv run --project ../../backend python build_seed_data.py
```

- `line_items.json` — 30 canonical corrugated-packaging SKUs: 22 popular RSC/mailer/document-box
  variants (PKG-101 to PKG-122) plus 8 specialty SKUs (PKG-201 to PKG-208) of the kind an
  Amazon/Walmart-grade packaging supplier carries — e-commerce mailers, packline-compatible
  cartons, retail-ready trays, corner boards, dunnage, cold-chain, export-rated, and POS display
  boxes. Each item carries spec attributes (ply, flute, dimensions, GSM, weight) used later for
  unit conversion.
- `questionnaire.json` — 8-question quality questionnaire (ISO/FSC certification, defect rate,
  batch testing, recycled content, Amazon APASS audit, lead time, certificate of conformance).
- `historical_prices.json` — last period's (FY2025) reference price per SKU.
- `vendors.json` — the 5 vendor personas and what each one tests.
- `vendors/ground_truth.json` — the authored "answer key" for every vendor's quoted lines and
  questionnaire answers, in canonical form. Meant for scoring the real extraction pipeline later,
  not for the buyer to see.
- `vendors/<slug>/` — each vendor's actual response file(s), in their target messy format:
